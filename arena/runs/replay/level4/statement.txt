LEVEL 4

[p2]
Now it’s your turn to calculate paths.
▪ You are given a list of lawns. Each lawn has one tree on it.
In this level, the tree is never on the edge of the lawn.
▪ For each lawn, find a valid path.
You can check the previous level for the definition of a valid path.
▪ You can choose the start and end cell.
▪ Every given lawn is solvable.
There are multiple correct solutions.
Hint: You can use your code from the previous level to validate your solution.
Hint: There is a visualizer.html in the input folder. You can use it to visualize lawn mower paths.
